What the numbers
actually mean.

Index Scan  (cost=0.42..8.44  rows=1  width=64)
cost=0.42..
startup cost
cost before first row emitted — index traversal, hash build, sort
..8.44
total cost
cost to emit all rows — what matters for most queries
rows=
est. rows
planner's guess based on table statistics, not a measurement
width=
avg bytes
average row width in bytes — affects sort & hash memory

Cost units are arbitrary. Compare plans relative to each other, not absolute numbers. These are estimates, not measurements.
