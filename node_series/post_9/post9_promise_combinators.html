Promise.all.

That's why one slow endpoint kills their whole batch.

// 10 webhook calls. One fails.
const results = await Promise.all(webhooks.map(send));
//                                 ↑
// ONE rejection → whole thing throws. 9 results lost.
The trap: independent tasks shouldn't share a fate. Use the right combinator, not the first one you learned.

$ # Promise.all — all-or-nothing

Promise.all
all must succeed.

// parallel DB lookups — all required
const [user, cart, prefs] = await Promise.all([
  db.getUser(id),
  db.getCart(id),
  db.getPrefs(id),
]);
// fast fail ↓
// ONE rejection → rejects. Other results discarded.
Use when:
all values required — no point continuing if one fails
Footgun:
independent tasks (webhooks, emails) → one failure nukes all

$ # Promise.allSettled — never throws

allSettled
fire all. collect outcomes.

// notify 10 webhooks — each independent
const results = await Promise.allSettled(
  webhooks.map(url => notify(url))
);
results.forEach(r => {
  if (r.status === 'rejected') logger.warn(r.reason);
});
Always resolves with array:  [{status:'fulfilled', value:...},
 {status:'rejected', reason:...}]
Never rejects. Every result preserved.

$ # race vs any — subtle but critical
Promise.race — first to SETTLE
// timeout pattern
const result = await Promise.race([
  fetchData(),
  new Promise((_,rej) =>
    setTimeout(() =>
      rej(new Error('timeout')),
      5000
    )
  )
]);
First to settle — resolve or reject.
Good for: timeouts, hedged requests
Promise.any — first to RESOLVE
// try N mirrors, take fastest
const data = await Promise.any([
  fetch(mirror1),
  fetch(mirror2),
  fetch(mirror3),
]);
// rejects only if ALL reject
// → AggregateError
Skips rejections. First resolved wins.
Good for: mirrors, fallbacks, CDN races

$ # see it yourself — same 3 promises, 4 combinators
const p1 = Promise.resolve('A');
const p2 = Promise.reject(new Error('B failed'));
const p3 = new Promise(res => setTimeout(() => res('C'), 100));

Promise.all([p1,p2,p3]).catch(e => console.log('all:', e.message));
//→ all: B failed

Promise.allSettled([p1,p2,p3]).then(r => console.log('settled:', r));
//→ settled: [{status:'fulfilled',value:'A'},
//            {status:'rejected',reason:Error},
//            {status:'fulfilled',value:'C'}]

Promise.race([p1,p2,p3]).then(v => console.log('race:', v));
//→ race: A  (p1 settles first — resolved)

Promise.any([p1,p2,p3]).then(v => console.log('any:', v));
//→ any: A   (p2 rejected, p1 first resolve wins)
race vs any: if p1 were rejected, race rejects, any continues to p3.

$ # tl;dr

Quick recap

  • all — all-or-nothing. one reject → whole thing fails
  • allSettled — never throws. collect every outcome
  • race — first to settle (resolve OR reject)
  • any — first to RESOLVE. rejects only if ALL reject
  • independent tasks → allSettled, not all
