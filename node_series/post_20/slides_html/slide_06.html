$ # gotcha #3 — new Date() in hot paths

new Date() costs.
Use Date.now().

Each new Date() allocates an object on the heap. Adds up fast in hot loops.

new Date()
→
heap alloc + GC pressure
→
~µs × 1M = real ms
Date.now()
→
returns a number
→
no alloc, fast
// BAD — allocates object every call
const ts = new Date().getTime();

// GOOD — number, no GC
const ts = Date.now();
