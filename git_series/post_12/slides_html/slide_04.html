fsck finds the rest.

When the reflog doesn't list it (e.g. you orphaned in a script), fsck scans for dangling objects.

$ git fsck --lost-found
dangling commit a7f3e91b8d4c2f1e6a9b8c7d5e4f3a2b1c0d9e8f
dangling commit b2c3d4e5f6789abc0123def456789abc01234567
dangling blob   c3d4e5f6789abc0123def456789abc012345678

Then inspect with git show <sha> to find the right one.
