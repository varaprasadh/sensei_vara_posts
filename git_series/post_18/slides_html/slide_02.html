$ # 2 ways git stores stuff

Loose files.
Then packs.

Every new object starts as a loose file in .git/objects/<2>/<rest-of-sha>. Eventually git bundles them into .pack files for efficiency.

$ ls .git/objects/ | head
a3    # first 2 chars of SHA
b7
c9
info/
pack/  ← where packfiles live

Loose = one-file-per-object. Packed = many objects in one file.
