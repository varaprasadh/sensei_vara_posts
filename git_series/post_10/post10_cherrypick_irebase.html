$ # grab one commit

Cherry-pick = copy one commit.

Take any commit by SHA and replay it onto your current branch. New SHA, same change.

$ git switch main
$ git cherry-pick f12a08d
[main 9b8c7d6] fix null check in auth

Useful when you don't want a whole branch — just one fix from it.

$ # rewrite your history

Interactive rebase = edit history.

Before you open a PR, polish your last N commits. Reorder, squash, drop, reword.

$ git rebase -i HEAD~5
# opens your editor with 5 commits to plan

Use only on local / unpushed work.

$ # what to never do

Don't do this to shared history.

Interactive rebase rewrites SHAs. If those commits are already on a remote others have, you're about to break their world.

$ git rebase -i HEAD~5   # rewrites SHAs
$ git push --force       # ← teammate's pulls now fail

Local feature branch? Rebase freely.
Shared main? Never.

Quick recap

  • cherry-pick — copy one commit by SHA to current branch
  • git rebase -i — edit your last N commits
  • pick / squash / reword / drop / fixup
  • polish locally before the PR
  • never rebase what others have already pulled
