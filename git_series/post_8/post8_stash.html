$ # the everyday move

Pause your work.

You're mid-feature when an urgent fix lands. Stash, switch, fix, come back.

$ git stash
Saved working directory and index state WIP on main: e89df01 add tests
# working dir is now clean — your edits are parked

$ git switch hotfix
# ... do the urgent fix ...

$ git switch main
$ git stash pop
# your edits are back

Park it. Switch. Fix. Pop it back.

$ # under the hood

Stash = a hidden commit.

It's not magic. Git creates a commit on a special stash ref and clears your working dir.

$ cat .git/refs/stash
a7f3e91b8d4c2f1e6a9b8c7d5e4f3a2b1c0d9e8f

$ git log --oneline stash
a7f3e91 WIP on main: e89df01 add tests

It's just a commit on a side branch you never see.

04 / 08
$ # working with multiple stashes

Many stashes?
No problem.

$ git stash list
stash@{0}: WIP on main: ...
stash@{1}: WIP on feature/api: ...
stash@{2}: WIP on main: refactor

# apply a specific one
$ git stash apply stash@{2}

# pop = apply + drop
$ git stash pop stash@{0}

# remove without applying
$ git stash drop stash@{1}

apply keeps it. pop removes it. drop deletes.

$ # pro moves

Name it.
Branch from it.

# name it so you can find it later
$ git stash push -m "wip: search refactor"

# turn a stash into a branch
$ git stash branch feature/search stash@{0}
# new branch, stash applied, stash dropped

Good for stashes you may not come back to today.

$ # what bites people

3 things to watch.

01
wrong branch on pop
Stashed on main, switched to feature, popped — now your edits are on the wrong branch. Stash again, switch back.
02
untracked files skipped
git stash ignores new (untracked) files by default. Use git stash -u to include them.
03
conflict on pop
Pop can conflict. Resolve manually — the stash stays put until you drop it.
04
stash isn't forever
Clear it out. Don't leave 47 stashes lying around — they pile up fast.

Stash is sharp. Hold it right.
