// what is a workflow?

Workflow: fixed control flow.

Steps are predetermined. You wrote down every transition before runtime.

input
→
step 1
validate
→
step 2
enrich
→
step 3
respond
→
output
// control flow lives in your code
const result = await validate(input)
  |> enrich
  |> llmCall   // exactly 1 LLM call
  |> respond;  // you decide what runs next

The LLM is one step, not the orchestrator.

// what is an agent?

Agent: LLM picks at runtime.

No fixed path. The model decides the next action based on what it sees.

// the agent loop
search()
⇄
LLM
decides
⇄
write()
read()
browser()

LLM is the orchestrator. It can loop, backtrack, pick any tool, any order.

  const clean = strip(email)
  const res = await llm({
    system: "summarize",

  })

// cost & latency multiplier

Agents = N× LLM calls.

Every tool call loops back to the model. That's another round-trip — another bill.

workflow
1 call
agent (3 tools)
4–6 calls (min)
agent (complex)
10–20+ calls — latency stacks
// at Sonnet rates — 1 complex task
workflow:  1 call  × $0.015  = $0.015
agent:    12 calls × $0.015  = $0.18  — 12× the bill

Latency scales the same way. Each call: +1–3s.

debug.js
06 / 08
// testability & debugging

Workflows are testable.

If the path can change every run, classical unit tests break.

workflow
predictable
Same input → same path, always
Unit test every step independently
Replay any failure exactly
CI passes or fails cleanly
agent
non-deterministic
Same input → different tool order
Needs evals, not unit tests
Failures are hard to reproduce
Needs LLM-as-judge to grade

Non-determinism isn't bad — just expensive to test. Price that in.

// the one question that matters

Can you write down the steps?

If yes, write a workflow. Only reach for an agent when you can't.

Do you know the control flow before runtime?
// yes
Use a Workflow
You can enumerate the steps. LLM is one node, not the router.
// no — it depends on runtime data
Use an Agent
Steps emerge from tool results. The model must orchestrate.

Open-ended research, debugging unknown codebases, complex multi-step plans → agent. Everything else → workflow.
