// what is a workflow?

Workflow: fixed control flow.

Steps are predetermined. You wrote down every transition before runtime.

input
→
step 1
validate
→
step 2
enrich
→
step 3
respond
→
output
// control flow lives in your code
const result = await validate(input)
  |> enrich
  |> llmCall   // exactly 1 LLM call
  |> respond;  // you decide what runs next

The LLM is one step, not the orchestrator.
