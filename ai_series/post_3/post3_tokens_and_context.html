math.js

// rough math you can do in your head

1 token ≈ ¾ of a word.

Common short words are 1 token. Long or rare ones split into pieces.

"weather"
1 token
"hippopotamus"
4 tokens
"🦛"
4 tokens
100 English words ≈ 130 tokens

Code, JSON, and emoji burn more tokens per character than prose.

// the model's working memory

Context window = RAM.

A fixed-size box. Everything the model sees this turn goes in it.

// context window — e.g. 200,000 tokens
system prompt~2k tok
tool definitions~3k tok
chat history (20 turns)~18k tok
new user message~200 tok
reserved for model output~4k tok

Everything in. Every. Single. Turn.

Quick recap

  • token — the model's vocab unit, ~¾ of a word
  • context window — fixed-size RAM, refilled every turn
  • System prompt + tools + history + reply all share the box
  • Full window → drop or error → forgetting
  • More tokens = more cost. Budget like RAM.
