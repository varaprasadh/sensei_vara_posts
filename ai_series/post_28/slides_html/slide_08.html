The default order.

  • 1
    Prompt engineering
    System prompt + few-shot. Free. Instant. Fixes 80% of "we need to fine-tune" cases.
  • 2
    RAG
    Inject external knowledge at runtime. Fixes domain knowledge gaps without training.
  • 3
    LoRA / PEFT
    Style / format consistency at scale. 1k+ examples needed. Try this before full FT.
  • 4
    Full fine-tune
    Last resort. Needs 5k+ examples, dedicated infra, and clear prompting failure evidence.
Most "we need to fine-tune" decisions are wrong.
Prompt first. Always.
