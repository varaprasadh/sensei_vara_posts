Append every turn.

Keep the full conversation array. Send it back. Every. Time.

const messages = [
  { role: "user",      content: "my order is late" },
  { role: "assistant", content: "share your order #?" },

// pick your tool

Two kinds of memory.

Different jobs. Different tradeoffs. Same goal: don't forget.

// short-term
scratchpad (chat history)
  • fast — no extra round-trip
  • lossless — exact wording kept
  • dead simple — just an array
  • fragile — drops on overflow
  • lives in context — eats tokens
  • gone when session ends
// long-term
library (vector store)
  • persistent — survives sessions
  • scalable — millions of facts
  • semantic — search by meaning
  • lossy — chunks, not transcripts
  • extra step — retrieve before reply
  • infra — embeddings + DB

Not either/or. Both have a role.
