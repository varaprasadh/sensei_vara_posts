// the default + override rules

The decision rule.

Default to API. Override when a specific condition triggers.

DEFAULT
Start with API-first. Fastest path to production. No hardware, no setup, no ops.
SWITCH when
latency matters — code completion, real-time features, sub-100ms required
SWITCH when
data is sensitive — PII, health records, private IP that can't leave your network
SWITCH when
cost > hardware — API bill exceeds ~$100/mo, hardware pays back in <6 months
The best model is the one that ships. Start simple, go local when the math says so.
