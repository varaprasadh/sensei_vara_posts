05 / 08
// top-k, briefly

Top-k = the shortlist.

Like top-p, but a fixed count instead of cumulative probability.

top_k = 40 → only consider the 40 most-likely tokens at each step.
top-k
Fixed count.
"Top 40 tokens. Always."
top-p
Fixed probability mass.
"However many add up to 0.9."

Most APIs let you set both. Filters stack.

06 / 08
// the rest of the panel

4 more dials.

Once temperature and top-p make sense, the rest is small stuff.

01
stop sequences
Strings that end generation early. e.g. "\n\n", "###".
02
max tokens
Hard cap on the length of the output. Stops generation no matter what.
03
frequency penalty
Discourages repeating tokens you've already seen in the output.
04
presence penalty
Discourages repeating topics. Encourages talking about new things.

Stop / max → where it ends. Penalties → how it varies.
