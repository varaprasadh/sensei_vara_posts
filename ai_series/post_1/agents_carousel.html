// step 1 — something you already know

A function call

You give it inputs. It gives you an output.

function sum(a, b) {
  return a + b;
}

sum(2, 3);  // → 5
2, 3 → sum() → 5

Two numbers in. One number out. Predictable.

// step 2 — same shape, different brain

A model call

Same idea as a function. Text in, text out.

const reply = await model({
  prompt: "Translate 'hello' to French"
});

// reply → "Bonjour"
text → model() → text

A model is just a function. With a wild imagination.

limits.js
04 / 08
// but here's the problem

A model can talk.
It can't do.

Ask it for today's weather — it can't look outside.
Ask it to send an email — it can't reach your inbox.

model("What's the weather in Tokyo?")

// → "I don't have access to
//    real-time data..."

A model alone is a brain in a jar.
It needs hands.

tools.js
05 / 08
// give the model some hands

Tools

Functions you let the model ask for by name.

const tools = [
  {
    name: "get_weather",
    run: (city) => fetch(...)
  },
  {
    name: "send_email",
    run: (to, body) => ...
  }
];

The model doesn't run them. It asks for them.

"Please call get_weather("Tokyo") for me."

// model + tools + a loop = agent

The agent loop

One model call isn't enough. So you call it. Again. And again.

1
Send goal + tools to model
2
Model picks a tool, e.g. get_weather("Tokyo")
3
You run the tool, get the result
4
Send result back, model decides next step
↻
Repeat until the goal is done

So what's an agent?

A loop that lets a model use tools to reach a goal.

Goal → model thinks → tool runs → model thinks again → done.
