01// infinite loop

The agent never stops.

Model keeps calling tools. Forever. Burning tokens and your wallet.

// the problem
turn 1: search("weather")
turn 2: search("weather today")
turn 3: search("current weather")
turn 4: search("weather now")
// ... 47 more turns
Model is "verifying" itself. Or never sees a stop condition.
// the fix
const MAX_ITER = 10;

while (step < MAX_ITER) {
  if (done) break;
  step++;
}
Hard cap on iterations. Plus a clear "done" signal in your system prompt.

02// hallucinated tool name

It calls a tool that doesn't exist.

Your registry has get_data. Model confidently calls fetchData().

// the problem
// registry:
["get_data", "send_email"]

// model calls:
fetchData({ id: 42 })
// → TypeError: not a function
Crashes — or worse, your runner silently skips it and the agent stalls.
// the fix
if (!tools[call.name]) {
  return {
    error: `Unknown tool: 
    ${call.name}. Available:
    ${Object.keys(tools)}`
  };
}
Validate names. Return the list back to the model — it'll retry with the right one.

03// context blowup

The window overflows.

History grows every turn. Tool results too. Eventually you hit the token limit.

// the problem
turn  1: 2k tokens
turn  5: 8k tokens
turn 10: 28k tokens
turn 20: 95k tokens
turn 25: ⚠ context_length_
           exceeded
Big tool outputs (HTML pages, query results) explode it fast.
// the fix
// summarize older turns
if (history.length > 20) {
  history = [
    summarize(old),
    ...recent10
  ];
}
Summarize, sliding-window, or store old turns in a vector DB (RAG).

04// silent tool failure

Tool throws.
Agent doesn't know.

Your fetch() 500s. Your try/catch swallows it. Model thinks the call succeeded.

// the problem
try {
  return await api(...);
} catch (e) {
  return null;
  // model: "Cool, success!"
}
Model proceeds with "no data" as if it were real. Hallucinates the rest.
// the fix
try {
  return { ok: true, data: ... };
} catch (e) {
  return {
    ok: false,
    error: e.message
  };
}
Surface errors back as data. Model sees them, adapts, or asks for help.

// the fix kit

Wire these in day one.

Cheap to add early. Expensive to retrofit after you've shipped.

01 — iteration cap
Hard stop at N turns
10–20 is usually enough. Log when you hit it — it's a smell.
02 — tool registry validator
Reject unknown names
Return the available list back so the model self-corrects.
03 — context budget
Summarize or slide
Cap turn count or token count. Drop oldest, summarize the rest.
04 — structured errors
Surface, don't swallow
Always return { ok, data } or { ok, error }. Never silent null.

Quick recap

  • infinite loop — cap iterations, define "done"
  • ghost tools — validate names, return list back
  • context blowup — summarize, slide, or RAG it
  • silent failures — wrap every tool with { ok, error }
  • Defensive plumbing > clever prompting.
