// the full pipeline

Tokens in, probabilities out.

Every transformer follows these steps. Text goes in, next-token probability comes out.

"The cat sat on the" → tokens [464, 3797, 3332, 319, 262]
↓
Embedding — each token becomes a 4096-dim vector
↓
Self-Attention × N layers — tokens learn about each other
↓
Feed-Forward Network — transform each token independently
↓
Output probabilities — "mat": 0.23, "floor": 0.11, "rug": 0.08...

That's it. Tokenize → embed → attend → feed-forward → predict. Repeated N times.

// step 1: embeddings

Words become vectors.

Each token maps to a high-dimensional vector. Similar meanings land near each other in this space.

// tokenize the input
"The cat sat" → [464, 3797, 3332]

// look up embedding for each token

embedding_3797 = [0.45, -0.21, 0.63, ... ]
embedding_3332 = [0.33, -0.55, 0.41, ... ]

// add positional encoding — WHERE in the sentence
token_0 = embedding_464  + posEncode(0)
token_1 = embedding_3797 + posEncode(1)
token_2 = embedding_3332 + posEncode(2)

// now each vector encodes WHAT + WHERE

// step 2: self-attention

Which tokens matter?

Self-attention lets each token look at every other token and decide how much to pay attention to it.

// the library analogy
key-query-value 
// you're searching a library

Query  = what you're looking for
         "animals that sit"

Key    = book spine labels
         "cat", "the", "sat"

Value  = the book's content
         [actual information]
Match query against keys. High match = read that book's value. Low match = skip it.
// the math
attention 
// for each token:
Q = token × W_q  // query
K = token × W_k  // key
V = token × W_v  // value

// attention score
score = softmax(Q · KT / √d)
output = score × V
Each token gets a weighted mix of all other tokens' information.

// multiple perspectives

Multi-head attention.

One attention head can only focus on one relationship. Multiple heads look at the sentence from different angles simultaneously.

head 1 — syntax
Grammatical role
"sat" attends to "cat" because cat is the subject. Tracks who did what.
head 2 — position
Nearby words
"sat" attends to "on" and "the" because they're adjacent. Local context.
head 3 — semantics
Meaning
"cat" attends to "mat" because both are nouns in a spatial relationship.
head 4 — coreference
Pronoun resolution
"it" attends back to "cat" across sentences. Tracks references over long distances.

// 96 different "perspectives" per layer, 120+ layers

// step 3: feed-forward + stacking

Stack it deep.

After attention mixes information between tokens, a feed-forward network transforms each token. Then repeat the whole block N times.

// one transformer block
function transformerBlock(tokens) {
  // 1. self-attention: mix information between tokens
  attended = selfAttention(tokens)
  tokens   = layerNorm(tokens + attended)  // residual

  // 2. feed-forward: transform each token independently
  ff     = feedForward(tokens)   // 2-layer MLP
  tokens = layerNorm(tokens + ff)     // residual

  return tokens
}

// stack N blocks — each layer adds understanding
for (layer = 0; layer < 120; layer++)
  tokens = transformerBlock(tokens)

// early layers: syntax, grammar
// middle layers: semantics, facts
// deep layers: reasoning, abstraction

// why transformers won

RNNs are serial. Transformers are parallel.

The key breakthrough: attention processes all tokens at once. RNNs read one token at a time.

// RNN (old)
  • Processes tokens one by one Token 5 must wait for tokens 1-4
  • Can't parallelize on GPUs Sequential bottleneck kills training speed
  • Forgets long-range context Info from token 1 fades by token 1000
// Transformer (new)
  • All tokens processed at once Full parallelism across sequence
  • GPU utilization near 100% Matrix multiplies on thousands of cores
  • Direct attention to any position Token 1000 can attend directly to token 1 
// training speedup
rnn_training         = O(seq_len)         // serial
transformer_training = O(1) with parallelism  // all at once
// → transformers train 10-100x faster on same hardware

The transformer in 5 lines.

  • Self-attention: each token asks "which other tokens matter to me?" via key-query-value
  • Multi-head: 96 attention heads look at syntax, semantics, coreference simultaneously
  • Feed-forward network transforms each token, then stack 120+ layers deep
  • Transformers beat RNNs because attention is parallel — all tokens processed at once
